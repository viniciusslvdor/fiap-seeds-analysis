# Análise de Sementes

Análise de machine learning aplicada ao dataset de sementes utilizando scikit-learn.

### Instalação
```
poetry install
```

### Uso

Abra o notebook `scikit-learn-ml-analysis.ipynb` e execute as células.

### Modelos Implementados
- KNN (K-Nearest Neighbors)
- SVM (Support Vector Machine)
- Random Forest

**Obs**: Uso do GridSearch para busca e otimização dos hiperparâmetros.

### Métricas Avaliadas
- Acurácia
- Precisão Média
- Recall Médio
- F1-Score Médio
